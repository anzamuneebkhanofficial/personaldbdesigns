# 🗄️ My Database Designs

Welcome to my personal database design portfolio! Here, I share the database schemas and ER diagrams I have designed for various projects. 

The goal of this repository is to keep all my database designs in one place and share them publicly so others can learn or use them for inspiration.

## 📂 Folder Structure
- **`resources/db_design_imgs/`** - Contains the actual images of the database designs, organized by project.
- **`resources/links/`** - Contains links to interactive tools (like dbdiagram.io) or references used for the designs.

## 🔗 Useful Links
Want to interact with these designs or see how they were made? Check out the **`resources/links`** folder in this repo for tools, cheat sheets, and live links.

## 🛠️ Tools I Use
- [dbdiagram.io](https://dbdiagram.io/) - For quick DBML coding.
- [drawSQL](https://drawsql.app/) - For visual diagramming.
